Architecture notes worth flagging
---------------------------------
- No build step, no package.json; all JS/CSS loaded at runtime with cache-bust via
  localStorage.expert_asset_v synced from expert_settings.asset_version.
- product/*.html is CI-generated — never hand-edit; .github/workflows/generate-seo.yml owns it.
- Admin auth uses synthetic emails <username>@expert-admin.internal; writes gated by
  is_admin(auth.uid()) in RLS. Account CRUD routes through admin-manage-accounts Edge Fn
  (service-role; the only path that can create Auth users).
- Checkout's stock write is anon-callable but goes through decrement_stock RPC (subtract-only)
  rather than a direct expert_stock write.
- offer_subscribers intentionally has no anon SELECT policy — avoid on_conflict upserts there.
